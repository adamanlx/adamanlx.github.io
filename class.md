## Schedule and homework

### Variables, operators, data types, `print()`

Install Python and VSCode. Be able to open a terminal in VSCode and successfully run the command `python -v`. Email Adam [aan@ku.edu](mailto:aan@ku.edu) an introduction about yourself, your research, and what you want to learn. Later class meetings will cover topics of student interest.

### The command line, conditionals, and `input()`

Think about a set of decisions you make in your daily life and model them using the new techniques from class. Incorporate numbers, strings, and nested conditionals.

### Lists and loops

By today at the latest I will have released a complete plan for the second half of the semester.

Make a Python version of [Wordle](https://hellowordl.net/).

### File input/output, csv, command-line arguments

Write a script that takes in a `.txt` file, sorts the lines alphabetically, capitalizes each line, and puts the results in a new `.txt` file. Then modify your script to work with `.csv` files as well.

### Git

Install git and make a GitHub or GitLab account. Create a repository and push several commits to it.

### Dictionaries and functions

Make a Python version of an ATM. Allow users to create accounts, sign in and out of accounts, and deposit and withdraw money. Come up with two or three new features and implement them. Hint: use a dictionary to associate account names with account balances.

Think carefully about things a user should *not* be allowed to do, like withdraw more money than they have, and test your program rigorously to ensure these can't happen.

Look for chances to put reused code in functions. Create a git repository for your ATM and push regularly with informative, imperative commit messages.

This larger-than-usual assignment asks you to synthesize all the fundamentals. You got this!

### Learning to learn: documentation

Continue looking up topics of interest. Email Adam [aan@ku.edu](mailto:aan@ku.edu) two or three final project ideas.
